# 🧠 Patient Risk & Financial Clustering App

O aplicație web de data science construită cu **Python** și **Streamlit**, care explorează două probleme de machine learning: clasificarea riscului de diabet și segmentarea clienților de credit card.

---

## 📌 Descriere

Aplicația oferă un mediu interactiv pentru explorarea datelor, testarea modelelor de clasificare și înțelegerea riscurilor medicale și financiare. Este structurată în mai multe pagini, fiecare cu un scop specific.

---

## 🗂️ Navigare

| Pagină | Descriere |
|--------|-----------|
| 📊 **Prezentare Dataset** | Explorează coloanele și valorile datasetului |
| 📈 **Statistici & Afișare** | Vizualizări grafice și analize descriptive |
| 🧠 **Modele de Clasificare** | Aplică și testează modele ML (Decision Tree, KNN, SVM, Random Forest) |
| 📌 **Concluzii** | Rezumatul rezultatelor și interpretarea modelelor |
| ❓ **Quiz** | Mini test interactiv pentru evaluarea cunoștințelor despre diabet |
